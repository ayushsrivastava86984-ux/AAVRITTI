# AAVRITTI

### One Platform. Multiple Possibilities.

AAVRITTI is a subscription-based platform that connects businesses with customers. It allows administrators to manage businesses, customers, and subscription plans from one place.

## Key Features

- Admin Dashboard
- Add and manage businesses
- Add and manage customers
- Create and manage business subscription plans
- Customer Dashboard
- Browse available businesses
- Explore subscription plans
- Purchase subscriptions

## User Roles

### 1. Admin
- Adds and manages businesses.
- Adds and manages customers.
- Creates and manages subscription plans.
- Manages platform information.

### 2. Customer
- Accesses the customer dashboard.
- Explores available businesses.
- Views subscription plans.
- Purchases subscriptions.

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
